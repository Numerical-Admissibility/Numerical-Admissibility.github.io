AP-1 Protocol

The Open Standard for AI Numerical Admissibility and Verifiable Operand Provenance in Mission-Critical Systems.

The Governance Challenge

In high-stakes corporate environments, an AI agent can perform ungoverned arithmetic or pass self-originated operands into deterministic tools. While the tool execution record remains valid, the inputs entering the calculation lack established provenance.

Instructing an LLM not to originate operands is merely a policy; verifying after execution that every consequential operand traces to an authoritative source is a control.

Core Dimensions Evaluated by AP-1

Operand Provenance

Verifies whether numerical inputs originate from authorized source data or ungoverned model calculations.

Operation Correctness

Audits multi-step derivation routes against governed calculation engines to ensure full compliance.

Refusal Integrity

Evaluates whether an agent correctly refuses execution when required data context or provenance is missing.
